# Reusable Components

Place framework-neutral specifications and reusable UI components here.

Good candidates:

- Search-focused service introduction
- Transparent pricing section
- Customer process section
- Frequently asked questions
- Author and editorial-trust panel
- Affiliate disclosure
- Related-content navigation
- Approval and preview status
- Measurement summary

Components must remain generic. Company names, prices, phone numbers, affiliate links, product claims, and private configuration belong in the adopting project.
