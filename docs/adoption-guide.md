# Growth Engine Adoption Guide

## 1. Copy only what the project needs

Choose the relevant technical helpers, templates, and workflow documents. Do not copy every library item automatically.

## 2. Create a project profile

Complete the site-profile template using verified owner-approved facts. Keep private or sensitive details in the project's protected configuration.

## 3. Establish the technical foundation

- Metadata base and canonical URLs
- Unique route metadata
- XML sitemap
- robots.txt
- Structured data appropriate to the business
- Mobile and accessibility checks
- Broken-link checks
- Search Console and analytics after deployment

## 4. Map opportunities

Score search opportunities by business value, relevance, attainability, and page readiness. Prefer one strong page serving a genuine customer need over many repetitive pages.

## 5. Use controlled publishing

Draft, verify, preview, approve, publish, and record. Major pricing, product, legal, medical, financial, or performance claims require source verification and owner approval.

## 6. Measure and improve

Use real impressions, clicks, leads, and conversions to determine the next work. Preserve the baseline and publication date so changes can be evaluated.
