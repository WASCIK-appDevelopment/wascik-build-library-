# WASCIK Build Library

Reusable foundations for websites, affiliate publishing, search discovery, analytics, and future WASCIK client builds.

## Current modules

- `growth-engine/` — continuous audit, opportunity, approval, publishing, and measurement workflow
- `seo/` — reusable Next.js metadata, robots, and sitemap helpers
- `content/` — site-profile and keyword-opportunity templates
- `affiliate/` — honest product-guide structure and evidence rules
- `analytics/` — Google Search Console and business-outcome measurement plan
- `components/` — specifications for reusable website sections
- `docs/` — adoption and implementation guidance

## Library rule

This repository stores generic, reusable systems. Company-specific contact details, credentials, customer information, prices, affiliate links, merchant claims, and private project configuration must remain in the adopting project's repository or protected configuration.
