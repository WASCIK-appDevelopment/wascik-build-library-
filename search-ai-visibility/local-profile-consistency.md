# Local Profile Consistency Checklist

Use one verified public identity across the website, Google Business Profile, Bing Places, Yelp, LinkedIn, Facebook, and legitimate directories.

## Identity record

Confirm before editing profiles:

- official public business name
- public telephone number
- public email
- production website
- primary category
- secondary categories
- hours
- service area
- delivery model
- public storefront status
- short and long descriptions

## Service-area business rule

If customers are not served at the address:

1. Keep the real address private in platform verification records when required.
2. Disable public address display.
3. Select only cities, ZIP codes, or regions actually served.
4. State that services are remote or performed at customer locations by appointment.
5. Do not call a residence a walk-in office.
6. Do not invent a public location to satisfy a listing form.

## Evidence register

For each profile record:

- profile URL
- verification status
- exact public name
- category
- public address visibility
- service area
- telephone and website
- last reviewed date
- screenshot or exported evidence
- warnings or requested documentation
- owner-approved next action

## Review safeguards

- Ask only genuine customers or organizations with direct experience.
- Do not buy, fabricate, prepopulate, or misleadingly incentivize reviews.
- Obtain permission before publishing attributed testimonials.
- A website testimonial does not create a platform review or guaranteed search stars.
